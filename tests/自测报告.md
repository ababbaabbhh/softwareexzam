## 5. 自测中发现并修复的问题

| 编号 | 问题 | 现象 | 修复 |
| --- | --- | --- | --- |
| T1 | 题库批次把中文考点名写入 `topic` | ft6/ft7/ft8 共 240 题被判为「未知模块」 | 按文件名推断模块兜底（ft6→OO、ft7→OS、ft8→NET 及前缀映射） |
| T2 | 主观题 JSON 含裸换行 | `sub1.json` 解析失败，17 题丢失 | `readBankFile` 增加字符串内裸控制字符转义后重试 |
| T3 | 填空题答案数组语义不一致 | 1 个空配了多个同义答案，被判为空数不匹配 | 归一化：空数 ≤1 且答案数 >1 时合并为 `A|B` |
| T4 | 无头浏览器字体缺失 | 所有文字元素高度为 0，Playwright 判定元素不可见 | 本地安装 `wqy-zenhei` / `dejavu` 字体并设置 `XDG_DATA_HOME`，文字渲染恢复正常 |
| T5 | Chromium 缺少系统库 | `browserType.launch` 报缺少 libnss3 等 | 以非 root 用户下载 deb 包并 `dpkg-deb -x` 解压，设置 `LD_LIBRARY_PATH` |
| T6 | 计时器格式与用例期望不一致 | 150 分钟卷显示 `2:29:59`，用例只接受 `mm:ss` | 调整用例接受 `h:mm:ss` 格式（显示更清晰，保留实现） |
| T11 | 练习队列用服务端游标会被网络重试多跳一题 | 请求重试导致位置推进两次 | 改为客户端 pos 游标 + 服务端只读顺序表，请求幂等 |
| T12 | 自测脚本新增用例漏写 await | 用例在汇总之后才执行 | 补上 await，用例数 36 |
| T10 | 部署在反向代理子路径下 | 只能通过代理入口访问 | 前端静态资源与接口改为相对路径（`PAGE_BASE`），根路径与 `/exam/` 子路径共用同一套代码 |
| T7 | 进行中重复开考 | 首次浏览器用例因残留进行中考试直接开始失败 | 用例前置清理/使用 409 续考逻辑；产品侧首页提示「继续作答」 |
| T8 | 真题多空题被去重 | 同一题干的第 N、N+1 空只保留一题 | 真题去重键加入 paper 与题号 |
| T9 | Playwright 版本与浏览器不匹配 | 升级后找不到 chromium | 将 playwright 固定为 1.49.0，与已下载浏览器版本一致 |

## 6. 复现方式

```bash
# 1) 启动服务
cd software_test
node server.mjs

# 2) 后端自测（独立临时库，不影响正式数据）
node tests/selftest.mjs

# 3) 浏览器自测（需先安装 playwright + chromium）
XDG_DATA_HOME=/tmp/fakehome/.local/share \
LD_LIBRARY_PATH=/tmp/chromium-libs/usr/lib/x86_64-linux-gnu:/tmp/chromium-libs/lib/x86_64-linux-gnu \
node tests/ui-test.mjs
```

> 字体与系统库的本地安装仅为本机无头浏览器测试所需，不影响产品运行；实际使用浏览器访问不需要这些。

## 7. 已知限制

1. 主观题为「标准答案 + 评分要点 + 人工自评」，不做语义自动评分。
2. 多选按「全对得分、少选/多选/错选不得分」处理（软考本身无多选，此为严格标准）。
3. 单用户系统：同一时间只允许一场进行中的考试，无账号体系。
4. 题库为按大纲与真题风格编写的模拟题，非官方原题，备考时建议结合官方教材与历年真题。
